# 初めての流れの切り替え（スライド式 ⇄ 初回体験）

2026-11-10 から、初めて開いた人には **スライド式チュートリアル** を出す（オーナー決定・モック `reports/tutorial-carousel-mock-2026-11-08/v6/`）。
以前の **初回体験**（その場で作品を選んで5語を試す流れ）はコードを残してあり、環境変数ひとつで戻せる。

## いまの動き（既定：スライド式）

`NEXT_PUBLIC_FIRST_RUN` が未設定、または `intro` の時。

1. スライド6枚（ようこそ／単語リスト／復習／クイズ／コレクション／拡張機能）— `components/IntroCarousel.js`
2. レベルの質問（1画面）。「スキップ」でもここは聞く
3. ホーム → ボタン案内（9か所）— `components/HomeTour.js`。終わると ＋（作品を追加）がそっと光る。作品がまだ無い人は最後の札が「作品を選んではじめる」
- ヘッダーの「? 使い方」からはスライド1〜6を見直せる（最後に「ボタンの案内も見る」）
- 今使っている人には自動では出さない
- 利用統計は `intro_*`／`tour_*`（集計表の ⑪）

## 初回体験に戻す手順

1. **戻す前に、初回体験の4作それぞれの配信先（`next-app/lib/trial.js` の `watchService`）を確認し直す。** スライド式の間は月1回の確認を止めているため、古いままの可能性がある。確認した日を `lib/trial.js` の冒頭のコメント（最終確認）に書く。
2. Vercel の本番の環境変数に `NEXT_PUBLIC_FIRST_RUN=trial` を足す（Production）。
3. `cd next-app && vercel deploy --prod --yes` で出し直す（`NEXT_PUBLIC_*` はビルド時に埋め込まれるので、出し直さないと効かない）。
4. 本番で、新しい端末（または `/app` を運営の印つきの別のブラウザ）で開き、初回体験の「ようこそ」が出ることを確かめる。

スライド式に戻す時は、環境変数を消して（または `intro` にして）出し直す。

## 共通の印

- どちらの流れでも、終えた（または抜けた）印は `cl_trial_done`（`lib/trialState.js`）を共有する。切り替えても、どちらかを終えた人にはもう自動では出ない。
- ＋ を一度でも押した端末は `cl_tour_add_used`（ボタン案内の終わりに ＋ を光らせない）。
