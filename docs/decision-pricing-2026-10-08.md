# 料金プラン設計の決定（2026-10-08・3部署討論 2R）

> ステータス: **討論で収束した案（ドラフト）**。価格・課金は最終的にオーナー承認が必要。転換率・価値の感じ方は実ユーザーで未検証（user-voice の声はシミュレーション）。法務見解は弁護士ではない部署の見解で、課金開始前に弁護士の単発レビューを受ける。

## 発端
オーナー案「無料版は新規生成を申請制、Normal プラン ¥200/月で自由に生成」を起点に、有料プランに含める機能・価格帯・無料版の新規生成の扱いを、marketing / user-voice / legal の3部署で討論した（R1 独立見解 → R2 敵対レビュー）。

前提（2026-10-08 時点）: AI 原価 ≈ ¥4/人/月（Haiku 5.5 化後・新規生成1話 ≈ ¥1）、固定費 ≈ ¥7,000/月、決済 3.6%、有料機能は未実装、OS 商用契約は未取得（ベータで利用者数を見てから）。

## 決定（3部署収束）

### 1. 無料版の新規生成 ＝ (b) 寛容な月間上限
- 無料（ログイン）: 新規生成は**月5〜10話**の上限。**生成済みの作品は無制限**。
- 有料: **新規作成枠の拡大**（「無制限」とは書かない＝公正利用の上限があるのに無制限と書くと景表法5条1号の優良誤認）。
- **申請制（オーナー案 a）は却下（3部署一致）**。理由:
  - 体験: 「今夜観る話を開いたら承認待ち」で初回に離脱する。コンセプト「観たいドラマが教材になる」と矛盾。
  - 法務: OS 由来の解析結果そのものが有料の価値の中心になり、30条の4但書・32条の主従/目的（「教材販売」評価）の防御が弱まる。「無料」と打ち出して実は申請制なら景表法の有利誤認の余地。
  - 原価: 1話 ≈ ¥1・共有キャッシュで全員に効く＝無料の寛容さはコスト増でなくカタログ資産の増加。
- 上限表示は罪悪感 UI にしない（「今月の新規作成枠は残り○話」を控えめに）。

### 2. 価格 ＝ 単一プラン ¥480/月（年払い ¥3,900）
- ¥200 は不可: 粗利がほぼ出ない（無料1,000人・転換4%で月 ¥8,000、固定費 ¥7,000 で赤字寸前）＋「安すぎて続くのか不安」。
- ¥680〜980 は今は重い: 有料機能が未実装・実績ゼロで、Language Reactor Pro（約$5）と並ぶと「劣化版なのに同額」に見える。
- 2段階（¥380→¥680）は却下: 未実装の今「どちらが自分向きか」を比べさせるのは作業感。後から ¥380→¥680 に上げると値上げ告知で不信。
- 上位プランは **AI 解説の原価が実測できてから**別枠で検討。
- 試算（無料1,000人・転換4%）: 40人 × ¥480 = 月 ¥19,200 → 決済 ¥700・AI ¥4,000・固定費 ¥7,000 を引いて **粗利 ≈ ¥7,500**（OS 契約料の前）。

### 3. 機能の線引き

| 区分 | 機能 |
|---|---|
| **無料（永久・法的に必須）** | 拡張の字幕クリック保存とホバー訳／**視聴中の再会（履歴・設定を含め全部）**＝Netflix の DOM 字幕がきっかけなので有料化は §1.8 の商用収益化＝赤／例文（1文の引用）と出所表示／実セリフ穴埋めクイズ／**単語・意味・SRS 履歴の書き出し（CSV/Anki）** |
| **無料（コア体験）** | 複数端末同期／共有済み単語リストの閲覧／新規生成（月5〜10話）／予習ウォークスルー／半券／基本 SRS 復習／単語帳（件数上限なし）／**シーン記憶カード**（7/1 決定どおり＝習慣ループの点火）／基本の通知 |
| **有料（¥480）** | 高度 SRS（無制限・優先度・スケジュール高度化）／学習統計の深掘り／語彙リユニオン（旗艦）／シーン記憶カードの仕組み強化（並べ替え・復習の高度化。セリフ本体は無料と同じ扱い）／通知の細かい設定／新規作成枠の拡大／AI 解説（BYOK・同額に含める）／書き出しの利便性（Anki 自動同期・整形テンプレ） |
| **有料不可（赤）** | 字幕の保存・表示・全文・ダウンロード／作品へのアクセス／例文付き書き出しそのものを特典にすること／視聴中の再会 |

- 書き出しに例文を含める場合は無料・有料で同条件。出典を例文と同じ欄に必ず入れ、1話あたりの件数に上限を設ける（48条の担保が切れる・1話一括は全文複製に近づく）。
- 単語帳の件数上限は不可（溜めた量に比例して詰む＝罪悪感 UI 寄り）。上限をかけるのは新規生成数だけ。

### 4. 訴求文言の禁止
- 有料の訴求に作品名・Netflix・「実セリフ」を使わない。
- 赤の例: 「好きなドラマを作り放題」「Netflix の新作を即教材化はプレミアム限定」「実セリフ例文は有料会員だけ」。
- 訴求の主役は復習・統計・語彙リユニオン。生成枠は料金表の最下段「その他」。

### 5. 課金開始までの順序（法務）
1. OpenSubtitles 商用契約（consumer agreement のキャッシュ・保持・再配布条項を一読）。**有料を1つでも始めれば無料層を含めサービス全体が商用**になる。
2. 法人化（推奨: 特商法表記で個人住所を出す負担・責任の遮断）
3. 特商法表記・有料条項つき利用規約・決済事業者を追記した PP・最終確認画面（特商法12条の6）・解約導線
4. 弁護士の単発レビュー
5. 課金開始

### 6. ベータ中にできる価格検証
- 可: アンケート・インタビュー・「準備中」と明示した事前登録（決済も申込受付もしない）。
- 不可: 予約課金・カード登録（実質的な申込＝特商法の対象）／存在しない通常価格を使った「通常¥780→¥480」の二重価格表示（景表法）。
- user-voice は ¥780 側の提示自体に反対（「劣化版なのに同額」）。→ 検証は ¥480 の受容度を聞く形にする。

## 追記: 復習とクイズの無料/有料（2026-10-08 オーナー案＋法務再確認）
- オーナー案: **無料＝「今日の復習」1日20語（固定・現行 DAILY_REVIEW_CAP=20）**／**有料＝作品・話ごとの復習＋毎日の復習語数のカスタマイズ＋作品・話を選んで後から解くクイズ**。
- 正式公開前（限定公開・利用者ほぼゼロ）なので、正式公開時に有料側へ置けば「取り上げ」にはならない（オーナー指摘）。課金開始が公開より後になる場合は、公開時に「有料予定（今は無料で試せる）」と明記する。
- 法務再確認: 上の表の「実セリフ穴埋めクイズ＝無料必須」は**予習フローのクイズ（今夜のリハーサル→半券）**を指す＝これは無料のまま。**復習画面の「作品・話を選んで解くクイズ」は条件付きで有料可（黄）**。復習カードも同じ理屈（決め手は「払うと見られるセリフが増えるか」＝増えなければ有料可・増えるなら赤）。
- 有料にする条件: ①有料で出るセリフは無料の単語リスト/単語帳でも見られる同じ1文に限る ②課金対象は仕組み（作品・話を選んで出題・採点・弱点の記録・出題数の設定）③1問1文・“ ” 囲い・📺SxE（字幕：OpenSubtitles）は無料と同水準 ④話ごとのクイズは台本順に並べず1回の出題数に上限＝**現行（QuizScreen の buildLocalQuiz: 1回5問・苦手>期日>新出の優先順）で充足済み**。
- 赤に転ぶ見せ方: 鍵の向こうにセリフをぼかしてチラ見せ／「実際のセリフでクイズ解き放題」「（作品名）の名ゼリフを全部クイズに」「Netflix で観た話をクイズに」／料金表に作品ポスター・タイトルロゴ。安全な表現=「好きな作品・話を選んで出題」「弱点を自動で記録」。

## 保留＝オーナー判断が必要
- ✅**複数端末同期＝無料で確定（オーナー 2026-10-08）**。理由: 「PC の拡張で集めてスマホで復習」が習慣ループの中心で、有料化すると無料ユーザーが核心体験の前に壁に当たる＋ベータで無料提供中の取り上げになる。7/1 決定（複数端末は有料）を置き換える。以下は検討時の記録→ 7/1 決定は「複数端末同期は有料（単一端末は無料）」。marketing・legal は有料可（条件: 単一端末の保存は絶対に失わせない）、user-voice（R1）は無料推し。**ただし同期は現在ベータで無料提供中**＝後から有料にすると「取り上げ」になる（ロードマップの「freemium は初日から設計・後で取り上げない」に反する）。選択肢: (i) 同期は無料のまま確定 (ii) 公開（ベータ終了）前に有料化を告知して切り替え (iii) 既存ユーザーは無料で据え置き、新規から有料。
- 価格 ¥480 と生成上限の具体値（月5話か10話か）の最終承認。
