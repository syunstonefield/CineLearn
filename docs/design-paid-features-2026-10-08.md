### 復習とクイズの無料/有料（オーナー 2026-10-08＋法務再確認／正典= decision-pricing「追記: 復習とクイズの無料/有料」）
- **無料＝「今日の復習」1日20語（固定・`DAILY_REVIEW_CAP`=20）**。
- **有料＝作品・話ごとの復習**（現行は無料で上限なし→正式公開時に有料側へ。限定公開・利用者ほぼゼロなので取り上げにならない。ベータ方針＝全員開放＋「正式版ではプラス」明示をそのまま適用）**＋毎日の復習語数のカスタマイズ（D 量）**。
- **クイズ**: 予習フローのクイズ（今夜のリハーサル→半券）は**無料必須**。復習画面の「作品・話を選んで解くクイズ」は**条件付きで有料可（黄）**。条件＝①有料で出るセリフは無料の単語リスト/単語帳でも見られる同じ1文に限る ②課金対象は仕組み（選んで出題・採点・弱点記録・出題数）③“ ”囲い・📺SxE（字幕：OpenSubtitles）は無料と同水準 ④台本順に並べず出題数に上限（現行 `buildLocalQuiz` の1回5問・苦手>期日>新出で充足済み）。
- 赤＝鍵の向こうにセリフをぼかして見せる／「実際のセリフでクイズ解き放題」「（作品名）の名ゼリフを全部」「Netflixで観た話をクイズに」／料金表に作品ポスター・ロゴ。安全な表現＝「好きな作品・話を選んで出題」「弱点を自動で記録」。

### 語彙リユニオンの無料/有料の境界
- **拡張の「視聴中の再会」（他作品の単語帳語・覚えた語のハイライトとホバー「再会 · 作品 SxE」、v1.2.9）は永久無料**＝有料リユニオンに含めない。理由: Netflix の画面字幕（DOM）に重ねる機能＝有料化は Netflix 規約 §1.8 の商用利用（赤）。かつ無料ユーザーがリユニオンの価値を知る入口。
- 再会の記録（`cl_reunions`）・ホームの再会カードも無料（決定表「履歴を含め全部」）。
- **有料＝自前データ（単語帳・SRS・共有キャッシュ）から計算するアプリ側の面だけ**: 作品横断の語彙地図（1語ごとに出会った作品・出典つき）／再会語のまとめ復習／次に観る作品の推薦／「今夜また出る語」予告（A案・字幕解析結果を見せるため**法務確認が要る**）。
- 一言で: 「また会えた」と気づくのは無料、その再会を集めて学習に生かすのが有料。

### 学習の育ちを見せる「3重の円」（オーナー発案・2026-10-08 確定）
- **中心の数字＝「覚えた」**（`isLearned`: 2回以上思い出せた・最短2日目から動く）。
- **内側の濃い円＝「マスター」**（`isMastered`: reps≥3・間隔≥21日・EF≥2.0。SM-2 上は無失敗で4回目の正解＝初回から約3週間後に到達）。
- **外側の淡い円＝「出会った」**（予習生成語＋拡張保存語・「知ってる」スキップは除く）。「未習得○語」のような不安表示はしない。
- **円は縮ませない**: 各値は「これまでの最高値（high-water mark）」で描く。同期は max マージ（infra-gotchas の流儀）。忘れて判定が外れても円はしぼまない＝罪悪感 UI を作らない。
- アニメーション: 開いた時に前回見た値→今の値へ広がり、差分だけ光る。暖色の金（シネマの配色）。`prefers-reduced-motion` で静止。
- ~~円の大きさ＝面積を語数に比例~~ → **下の「円の見た目・配置の確定」で「弧の長さ（割合）」に置き換え**。（当初記録: 円の大きさ＝面積を語数に比例（オーナー 2026-10-08）。半径比例（量の誇張）・固定サイズのドーナツ型は不採用。注意: 初期はマスターが極小（例 7/349 語→外円の半径の約14%）になる＝中の数字の置き方を UI で決める。
- **✅ 円の見た目・配置の確定（オーナー 2026-10-08）**＝オーナー UI 案（`CineLearnRingUI`：300／240／180 の3本の円弧・線幅11・光る中心の円・右に凡例・「✦…」カード・舞う光）をベースに:
  - **中心の円＝覚えた**（数字）＋小さく「うち マスター N」（0の間は出さない）。円弧は外＝出会った・中＝覚えた・内＝マスター。
  - **円弧の長さ＝語数÷段階の枠**（枠＝100→250→500→1000→2000→4000→8000→16000語。出会った語数が収まる最小の段階）。段階の中では弧は伸びるだけ。段階を超えた時だけ全部の弧が一度短くなる＝「世界がひろがった」演出。「出会った＝いつも満周」は出会った語が増えると他の弧が縮むので不採用。
  - 開いた時の動き＝前回見た値→今の値（0からではない）・増えた分の弧だけ光る・マスター→覚えた→出会ったの順に少し遅らせる（UI 案どおり）・`prefers-reduced-motion` で静止。
  - 凡例の説明: 出会った＝~~「予習や視聴中の保存で出会った語」~~→「これまでに出会った語（棚から外した作品も含む）」（2026-10-08・ホームの分母＝今の棚の作品だけ とのずれを説明）／覚えた＝「2回以上思い出せた語」／マスター＝「3週間あけても思い出せた語」（0の間は「約3週間後から増えます」）。
  - カード文言は「前回から ○語 覚えた語がふえました」。基準の無い進捗バーは置かない。円に「タップで詳しく ›」。
  - 単語カードは例文に作品名＋字幕の出所（48条）を必ず付ける・出会っただけの語は並べない・**画像は作品のポスター（既存の TMDB ポスター `posterPath`）にする（オーナー 2026-10-08）**＝場面の静止画・映像のコマは使わない。
  - 確定モック: https://claude.ai/artifact/9eUzWAJ3sK9EpY4fB4S6x6
- （経緯）配置の叩き台（オーナー確認中）: 中心の大きな数字＝覚えた／その下に小さく「うち マスター N」（0の間は出さず凡例に「約3週間後から増えます」）／マスターの芯は数字の背後で育ち、数字より大きくなったら数字の色を反転。⚠**面積比例で外円を常に満杯にすると、出会った語が増えた瞬間に内側の円がしぼんで見える**（縮まない約束を見た目で破る）→ 提案＝枠を 100→250→500→1000…語の段階に固定し、段階の中では広がるだけ・段階を超えた時だけ一度引いて見せる。配置モック: https://claude.ai/artifact/9eUzWAJ3sK9EpY4fB4S6x6
- オーナーの UI 案（2026-10-08・画像）へのレビュー: ①中心の数字が「マスター」になっている（確定仕様は中心＝覚えた）②凡例の「意味を理解した」「完全に覚えた」は判定と合わない・効果の言い過ぎ ③進捗バーの満タンの基準が無い・「今日」と「前回比」が混在 ④「最近覚えた単語・シーン」の場面写真は映像のコマなら不可（DRM/著作権）・TMDB のエピソード静止画でも legal 確認が要る・例文に作品名と字幕の出所（48条）が無い ⑤円をタップできる手がかりが無い。
- ✅**円の有料/無料は保留＝全部完成してから決める（オーナー 2026-10-08・decision-pricing に記録済み）**: 有料機能の柱＝「作品別復習・円・学習記録」。**円そのものを有料にするかは保留＝全部完成してから決める**（タップ先が弱ければ円自体を有料にしてもよい・円のリッチさが課金時の満足度になる）。→ 実装は「円は無料」で固定せず、無料／有料を後から切り替えられる作り（表示の出し分けを後から足せる）にする。円もタップ先も見た目のリッチさ重視。法務: 円は自分の学習データだけ＝有料でも問題なし。有料にする場合も無料ユーザーに存在を知らせる見せ方（ベータ中は全員開放＋「正式版ではプラス」・料金ページの見本の絵）は必要。下の「円そのものは無料」はこの共有で**保留**（全部完成してから決める）。「作品別復習」＝復習ハブでの作品ごとの復習（条件復習の一部）と解釈＝語彙のあゆみの作品別タブ廃止とは矛盾しない。
- ~~円そのものは無料~~ → **完成後に判断**（上の行）。当初案＝円は無料・タップ先が有料（7/5 決定「激励無料・分析有料」の線）。どちらになっても、有料部分をぼかして見せる UI はしない（7/5 決定）。

### 有料SRSの中心＝「条件で絞って復習」（オーナー 2026-10-08）
- **中心 A＝条件で絞って復習**: 苦手語だけ／作品・シーズン／句動詞・イディオム／保存元（拡張・予習）／期日前の前倒し を組み合わせて出題。
- **同梱 D＝量とペース**: 今日の復習の語数（10〜全部）・1日の上限・曜日ごとの量。**同梱 E＝⭐優先語の固定**。
- 後回し: B 試験日モード（A の条件の一つとして後から足せる）／C FSRS（重い・効果主張に裏付けが要る）。
- 前提（2026-10-08 コード確認）: 今日の復習＝全作品・期日→未学習・日替わりシャッフル・`DAILY_REVIEW_CAP`=20／エピソード別復習は現行無料・上限なし→**オーナー決定で有料側へ移す**（上の「復習とクイズの無料/有料」）／採点3段階＋知らなかった語の再挑戦／苦手判定＝`isStruggling`（EF<2.0）。
- **無料に置く**: 休み明けの期日自動分散（罪悪感対策）。20語は「上限」でなく「今日のちょうどいい量」と見せる。

### ✅ 作品別復習に絞り込みを入れる（オーナー 2026-10-08）＝「条件を選んで復習」の置き換え
- 前提の変化: ①苦手判定の廃止 ②作品・話ごとの復習が有料の柱（「作品別復習」）に ③アプリの★は「単語帳に入っている」印（拡張保存語は最初から★）＝「⭐優先語を毎回混ぜる」は「単語帳を全部混ぜる」になり成り立たない。
- **条件シートは作らない**。作品別復習（復習ハブの作品→話の一覧＝既存）の中に絞り込みを入れる。

| | 無料 | プラス |
|---|---|---|
| 毎日の復習 | 今日の復習（全作品横断・期日の来た語から）・**語数の変更（10／20／30／50／全部）も無料（オーナー 2026-10-08 変更）**・休み明けの期日を自動分散・休む曜日 | ― |
| 作品別復習（柱） | ― | 作品／シーズン／話を選んで復習（既存の一覧を使う＋作品・シーズンまとめての復習を追加） |
| 範囲の中の絞り込み | **マスター手前（今日の復習の真下のカード・無料）** | 句動詞・保存元・前倒しの絞り込みは**作らない**（オーナー 2026-10-08） |
| 作品別クイズ | 予習のクイズ（無料必須） | 作品・話を選んで解くクイズ（法務の条件つき・「復習とクイズの無料/有料」節） |

- **マスター手前（オーナー 2026-10-08 残す）**: 定義＝「次に思い出せればマスターになる語」＝マスターでなく、`reviewWord` の計算で次に「完璧」と答えた時に reps≥3・間隔≥21日・EF≥2.0 を満たす語（判定を storage.js に1関数で持つ。苦手判定とは無関係）。⚠前倒しの正解はスケジュールを進めない規則なので、**期日前のマスター手前の語は解いてもマスターにならない**＝期日の来た語を先に出し、期日前の語には「今日は練習（マスターは期日に）」と表示する。
- **やめる**: 苦手な語だけ・⭐優先語・CEFR レベルでの絞り込み・ワンタップのおすすめ・「マイ復習」の保存。
- **残す規則**: 前倒しの成功はスケジュールを進めない（失敗は常に記録）。
- 見せ方: ベータ中は全員開放＋作品別復習の見出しに「正式版ではプラス」。
- 重さ: 1.5〜2日（作品・シーズンまとめ復習と絞り込み 約1日／語数設定 0.5日／`isPro` の土台）。
- **✅ 画面（オーナー 2026-10-08・スクショで確認）**: 作品別復習の画面は**今の復習タブ（`ReviewHubScreen`：今日の復習カード → マイ単語帳 → 作品ごとの話の一覧＝覚えた%・マスター%・復習数・クイズ）のまま**。新しい画面は作らない。範囲の中の絞り込み（句動詞・保存元・前倒し）と作品・シーズンまとめての復習は**保留**（画面を変えない方針と合わせて、要るか後で判断）。→ **✅決定（オーナー 2026-10-08）: 絞り込みは作らない**。**まとめ復習は作る＝作品見出しの「復習 N」バッジを押すと、その作品の全話から期日の来た語をまとめて復習**（今はバッジが押せそうで押せない＝見た目と動きを一致させる。オーナーは「今でもできる」と思っていた）。プラス（作品別復習の一部）。0.2〜0.3日。**F で実装**。シーズンまとめは作らない。
- **✅ マスター手前の置き場所＝「今日の復習」カードの真下**（1枚のカード）。**✅無料（オーナー 2026-10-08）＝カードも、そこから始める復習も全員が使える**（プラス表示は付けない）。
  - 補足: 期日の来たマスター手前の語は、もともと今日の復習に優先して入っている（期日の来た語が先）＝無料にしても「今日の復習」の一部を切り出して見せるだけで、原価も取り上げの心配も小さい。円のマスターの弧を伸ばす入口＝励まし側の機能。
  - 見せ方の叩き台: 「あと1回でマスター　○語（今日できるのは△語）」＋「はじめる」。0語の間（始めて3週間ほど）はカードを出さない。期日前の語しか無い日は「次は○/○から」とだけ出す（解かせない＝練習でマスターにならない落胆を作らない）。

### 「条件を選んで復習」の画面設計（2026-10-08 叩き台・オーナー合意の方向）　※上の「作品別復習に絞り込みを入れる」で置き換え
- **入口**: 復習ハブ（`ReviewHubScreen`）の「今日の復習」カード直下に「🎯 条件を選んで復習 ｜プラス」の1行＋保存した「マイ復習」（最大5）。
- **条件シート**: 上段＝ワンタップのおすすめ3つ（苦手な語だけ／次に観る作品の前に＝最近の作品を自動選択／句動詞・イディオムだけ）。中段＝条件チップ（段内 OR・段間 AND）: どの語（苦手・⭐・未習得・マスター手前）／どこの語（作品複数→シーズン）／種類（単語・句動詞イディオム＝複数語 or chunk・CEFR レベル＝生成語のみ）／出どころ（視聴中に保存・予習）／タイミング（期日のみ・前倒し含む）。下段固定＝該当語数のライブ表示・語数（10/20/30/全部）・はじめる。0件はエラーにせず条件のゆるめ方を提案。名前を付けてマイ復習に保存。
- **復習中**: `ReviewModal` をそのまま使う。**前倒しの成功はスケジュールを進めない**（既存の同日2回目＝練習扱いと同じ規則。進めると間隔が伸び「覚えたつもり」が量産され SRS が壊れる）。失敗は常に記録。
- **D 量**: 設定「復習のペース」＝今日の復習の語数（10/20/30/50/全部）・1日の上限が有料。**休む曜日は無料**（罪悪感対策）。
- **E ⭐**: ⭐を付けるのは無料（ただの印）。有料＝⭐語を今日の復習に毎回混ぜる（1日最大5）・条件に使う。

#### 叩き台からの修正提案

- 各行: ポスター小（予習履歴の `posterPath`・無ければ頭文字）／作品名／積み上げ横棒（マスター・覚えた・出会った）／「出会った 120・覚えた 45・マスター 12」／学習時間（`getDramaStudySeconds`・0なら出さない）。
- 語の所属は1語1作品＝**最初に出会った作品**（`origin` → `_src` → 単語帳の `dramaTitle` の順）。だから全作品の合計＝全体の数になる。
- ⚠作品名は邦題/英題で揺れる（単語帳の `dramaTitle`）→ グループ化は `sameTitle` で寄せる。
- 行をタップ→下から小さなシート: シーズン別の数（ドラマのみ）／「この作品の語で復習」→「条件を選んで復習」の条件シートを**作品を選んだ状態で開く**（いきなり始めない＝語数を選べる）／「この作品のつまずきやすい語」→C タブを作品で絞って表示。

**レベル別タブ**
- 行＝A2・B1・B2・C1・C2・「レベル未判定（視聴中に保存した語など）」。各行に作品別と同じ積み上げ横棒と数。
- レベルの出どころ: 予習生成語の `level`。拡張で保存した語は、同じ語が予習リストにあればその `level`、無ければ未判定。
- 見出し横に「CEFR の目安」。下に注記「レベルは AI による目安です。予習では今の実力より易しい語を省いているので、易しいレベルの語は少なめに出ます。」（誤読と罪悪感の予防）。TOEIC の点数・語彙サイズの推定は出さない。
- 行タップ→条件シートをそのレベルで開く。

**つまずきやすい語タブ（C）**
- 対象＝復習を始めた語のうち `isStruggling`（EF<2.0＝一度思い出せなかった）。見出し「思い出しにくかった語の傾向」。「弱点」「克服」とは書かない。
- **傾向は割合で出す**（数だけだと語の多い分類が常に上に来る）: 各行「動詞 12語／復習した 40語のうち 30%」。分母5語未満の行は出さない。割合の高い順。
- 分類: 種類（名詞・動詞・形容詞・副詞・句動詞やイディオム＝複数語の語）／作品／レベル。品詞は生成語の `pos`（4分類）・空の語は「その他」。
- 各行に「この語だけ復習（12）」→条件シートを「苦手な語だけ＋その分類」で開く。
- 下に「思い出しにくかった語」一覧（EF の低い順に最大20・語／意味／出会った作品）。
- **少ないうち**: 苦手語が10語未満なら傾向は出さず、一覧だけ＋「まだ傾向が出るほど集まっていません（いま N 語）」。0語なら「思い出せなかった語はまだありません」。

**空のとき**: 語が0なら画面全体を「予習か、視聴中の保存で、ここに内訳が出ます」だけにする。

**正式版で無料の人が円をタップしたら**: ぼかした自分のデータは見せない。「この画面はプラスの機能です」＋見られる内容の説明（文章と固定の見本図）だけ。急かす文言なし。円そのものはこれまで通り。

**実装メモ**
- 集計は端末内（`loadSrs`・予習履歴・単語帳）で `useMemo`。数千語でも軽い。API 追加なし。

- 条件シートへの受け渡しは、条件の初期値（作品・レベル・種類・苦手のみ）を渡して開く形。
