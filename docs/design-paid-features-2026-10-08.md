# 有料プラン（¥480）機能の詳細設計（2026-10-08・オーナーと詰め中）

> ステータス: **オーナーとの対話で順次確定中**。前提＝ docs/decision-pricing-2026-10-08.md（機能の線引き・禁止文言・課金順序）。有料機能は未実装・課金開始は OS 商用契約の後。

## 確定事項

### 有料の「払う理由の主役」＝2本柱（オーナー 2026-10-08）
1. **高度SRS＋学習統計**（手堅い・安い・法務クリーン）
2. **語彙リユニオン（アプリ側）**

### 語彙リユニオンの無料/有料の境界
- **拡張の「視聴中の再会」（他作品の単語帳語・覚えた語のハイライトとホバー「再会 · 作品 SxE」、v1.2.9）は永久無料**＝有料リユニオンに含めない。理由: Netflix の画面字幕（DOM）に重ねる機能＝有料化は Netflix 規約 §1.8 の商用利用（赤）。かつ無料ユーザーがリユニオンの価値を知る入口。
- 再会の記録（`cl_reunions`）・ホームの再会カードも無料（決定表「履歴を含め全部」）。
- **有料＝自前データ（単語帳・SRS・共有キャッシュ）から計算するアプリ側の面だけ**: 作品横断の語彙地図（1語ごとに出会った作品・出典つき）／再会語のまとめ復習／次に観る作品の推薦／「今夜また出る語」予告（A案・字幕解析結果を見せるため**法務確認が要る**）。
- 一言で: 「また会えた」と気づくのは無料、その再会を集めて学習に生かすのが有料。

### 学習の育ちを見せる「3重の円」（オーナー発案・2026-10-08 確定）
- **中心の数字＝「覚えた」**（`isLearned`: 2回以上思い出せた・最短2日目から動く）。
- **内側の濃い円＝「マスター」**（`isMastered`: reps≥3・間隔≥21日・EF≥2.0。SM-2 上は無失敗で4回目の正解＝初回から約3週間後に到達）。
- **外側の淡い円＝「出会った」**（予習生成語＋拡張保存語・「知ってる」スキップは除く）。「未習得○語」のような不安表示はしない。
- **円は縮ませない**: 各値は「これまでの最高値（high-water mark）」で描く。同期は max マージ（infra-gotchas の流儀）。忘れて判定が外れても円はしぼまない＝罪悪感 UI を作らない。
- アニメーション: 開いた時に前回見た値→今の値へ広がり、差分だけ光る。暖色の金（シネマの配色）。`prefers-reduced-motion` で静止。
- **円そのものは無料**（やる気の源＝習慣ループの燃料。7/5 決定「統計＝激励無料・分析有料」と一致）。**タップした先の詳細が有料**。有料部分をぼかして見せる UI はしない（7/5 決定）。

### 高度SRS＋統計の線引き（叩き台・オーナー合意の方向）

| | 無料 | 有料（¥480） |
|---|---|---|
| 復習の量 | 1回20語 | 1回の語数を自由に設定（10〜全部） |
| 出題の選び方 | 期日順＋苦手語の優先表示 | 苦手語だけ／作品・シーズン別／句動詞・イディオムだけ／保存元別（拡張・予習）／⭐優先語の固定 |
| スケジュール | SM-2 おまかせ／**休み明けにたまった期日を数日に自動分散（罪悪感対策＝無料）** | 試験日逆算モード（TOEIC 日付→間隔を詰める）／1日の上限・曜日ごとの量 |
| 統計 | 3重の円・連続日数・今週の数・学習時間 | 円の内訳（作品別・TOEIC 帯別カバー率の目安）／定着率の週ごとの推移／忘れやすい語の傾向（品詞・作品）／月ごとの語彙プロフィール |

- 語彙サイズ・カバー率は「目安」と明記（効果主張は研究の範囲のみ）。
- 実装目安: 円 0.5〜1日／絞り込み・語数設定 1〜2日／試験日モード 1〜2日／統計詳細 2〜3日。既存 SRS データ（`easeFactor`/`interval`/`origin`）で作れ、API 追加はほぼ不要。

### 有料SRSの中心＝「条件で絞って復習」（オーナー 2026-10-08）
- **中心 A＝条件で絞って復習**: 苦手語だけ／作品・シーズン／句動詞・イディオム／保存元（拡張・予習）／期日前の前倒し を組み合わせて出題。
- **同梱 D＝量とペース**: 今日の復習の語数（10〜全部）・1日の上限・曜日ごとの量。**同梱 E＝⭐優先語の固定**。
- 後回し: B 試験日モード（A の条件の一つとして後から足せる）／C FSRS（重い・効果主張に裏付けが要る）。
- 前提（2026-10-08 コード確認）: 今日の復習＝全作品・期日→未学習・日替わりシャッフル・`DAILY_REVIEW_CAP`=20／エピソード別復習は**既に上限なし（無料）**＝「語数自由」単体は差が弱い／採点3段階＋知らなかった語の再挑戦／苦手判定＝`isStruggling`（EF<2.0）。
- **無料に置く**: 休み明けの期日自動分散（罪悪感対策）。20語は「上限」でなく「今日のちょうどいい量」と見せる。

### 「条件を選んで復習」の画面設計（2026-10-08 叩き台・オーナー合意の方向）
- **入口**: 復習ハブ（`ReviewHubScreen`）の「今日の復習」カード直下に「🎯 条件を選んで復習 ｜プラス」の1行＋保存した「マイ復習」（最大5）。
- **条件シート**: 上段＝ワンタップのおすすめ3つ（苦手な語だけ／次に観る作品の前に＝最近の作品を自動選択／句動詞・イディオムだけ）。中段＝条件チップ（段内 OR・段間 AND）: どの語（苦手・⭐・未習得・マスター手前）／どこの語（作品複数→シーズン）／種類（単語・句動詞イディオム＝複数語 or chunk・CEFR レベル＝生成語のみ）／出どころ（視聴中に保存・予習）／タイミング（期日のみ・前倒し含む）。下段固定＝該当語数のライブ表示・語数（10/20/30/全部）・はじめる。0件はエラーにせず条件のゆるめ方を提案。名前を付けてマイ復習に保存。
- **復習中**: `ReviewModal` をそのまま使う。**前倒しの成功はスケジュールを進めない**（既存の同日2回目＝練習扱いと同じ規則。進めると間隔が伸び「覚えたつもり」が量産され SRS が壊れる）。失敗は常に記録。
- **D 量**: 設定「復習のペース」＝今日の復習の語数（10/20/30/50/全部）・1日の上限が有料。**休む曜日は無料**（罪悪感対策）。
- **E ⭐**: ⭐を付けるのは無料（ただの印）。有料＝⭐語を今日の復習に毎回混ぜる（1日最大5）・条件に使う。
- 法務: 対象は自分で保存した語＝作品へのアクセス課金ではない。訴求に作品名を使わない（例「苦手だけ、狙って復習」）。
- 重さ: 1.5〜2.5日（条件シート 1〜1.5／マイ復習 0.5／D・E 0.5）＋有料判定 `profiles.plan` の土台。
- **無料ユーザーへの見せ方＝ベータ中は全員に開放し「正式版ではプラスの機能です」と最初から明示（オーナー 2026-10-08）**。後から有料化しても「取り上げ」にならないよう、初日から表示する。急かす文言（「今だけ無料」等）は使わない。正式版移行後も保存したマイ復習・学習記録は消さない（ベータ規約の約束と一致）。

### ベータ方針＝有料機能は全員に開放＋「正式版ではプラス」を初日から明示（オーナー 2026-10-08・全有料機能に適用）
デメリットと対策:
1. **正式版移行時の落胆**（明示していても、使い慣れた機能が閉じると損失に感じる）→ 移行は30日以上前に告知。ベータ参加者への特典（例: 初年度の年払いを実際に割り引く）を検討。存在しない通常価格を使った二重価格表示はしない。
2. **ベータ中は「払うか」が測れない**（使用率は測れる＝どの有料機能が使われるかの検証には逆に好都合）→ 支払意思はアンケート・「準備中」事前登録で別に測る（decision-pricing §6）。
3. **ラベルは片道**（プラス→無料は「増える」ので可、無料→プラスは「取り上げ」で不可）→ **プラスの表示は有料で確実なものだけ**に付ける。迷う機能（場面から思い出す復習・通知の時刻指定など）は付けない。
4. **法務**: 価格・申込を出さないラベルだけなら課金開始ではない。ただし OS は現状「非商用」契約＝将来の有料を告知する段階で、OS 商用契約の打診時期とずれないよう legal に一度確認する。
5. **原価**: 今の有料候補は AI を使わないので全開放でも原価はほぼゼロ。**例外＝AI 解説**（開放すると費用が利用者数に比例）＝この方針の対象外として、設計時に別途決める。
6. 実装: 最初から `isPro`（`profiles.plan`）の判定と「ベータ中は全員 true」のサーバー側フラグを入れておく。正式版はフラグを切り替えるだけにする。
