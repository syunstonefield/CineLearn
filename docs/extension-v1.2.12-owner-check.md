# 拡張 v1.2.12 の実機確認（オーナー向け・1枚）

v1.2.12 には、v1.2.11 の「入れた直後にアプリを開く」も入っています。この確認が済んだら提出の準備に進みます。
**普段使っている Chrome には何も入れません。** 確認専用の Chrome プロファイルを作って、その中だけで行います。

## 用意するもの
- PC の Chrome と、Netflix などで英語字幕が出せる作品（ふだん観ているもので構いません）。
- **確認用のアカウントを2つ**（A と B）。普段のアカウントは使わないでください。アプリの「新規登録」で自分で作ります。メールアドレスは受け取れるものを2つ用意してください（Gmail なら、アドレスの @ の前に「+cl1」「+cl2」を付けると別のアドレスとして使えます）。
- 時間: 手を動かすのは40〜60分。最後の確認（手順9・10）だけ、途中で1時間ほど待ちます。

## 準備（10分）
1. **確認用のプロファイルを作る**: Chrome の右上の人のアイコン →「追加」→「アカウントなしで続行」→ 名前を「CineLearn 確認」にする。新しいウィンドウが開きます。以降はこのウィンドウだけで作業します。
2. **拡張を読み込む**: そのウィンドウのアドレス欄に `chrome://extensions` と入れる → 右上の「デベロッパー モード」をオン →「パッケージ化されていない拡張機能を読み込む」→ 次のフォルダを選ぶ。
   `/Users/ishiharashunichi/cinelearn/dist/CineLearn-extension-v1.2.12-check`
   （Finder で ⌘⇧G を押してこの文字を貼ると開けます）
   - 一覧に「CineLearn – 海外ドラマ・映画で英語学習｜字幕の英単語を場面つき単語帳に」「1.2.12」と出ればOK。
   - **同時にアプリのタブが開き、「新規登録」の画面で始まること**を確かめます（v1.2.11 の分）。
   - 確かめたら、**そのタブのアドレス欄に `https://cinelearn-next.vercel.app/app?cl_staff=1` を入れて開きます**（このプロファイルを「運営の端末」にして、利用統計に数えないための印。画面は変わりません。ログアウトしても消えません）。

## A. 2つのアカウントを切り替える（20分）
3. 開いたアプリで **A を新規登録**してログイン。動画を開き、字幕の単語を1つ（X）クリック →「✓ 保存」。アプリの単語リストに X が出ることを確かめます。
4. アプリでログアウト → **B を新規登録**してログイン。同じ話を開き直し、**X に保存済みの色の印が付かない**こと、クリックしても A の訳や「再会」の表示が出ないことを確かめます。
5. B で、**別の話**を開いて X を「✓ 保存」。B の単語リストの X に **B の作品だけ**が付き、A の作品が出ないことを確かめます。
6. ログアウトして **A に戻る**。動画を開き直すと X に印が戻り、A のリストに B の語が増えていないことを確かめます。
7. A でログアウト → **もう一度 A でログイン**。印とリストが変わらないことを確かめます。

## B. 「★ 覚えたい」（10分・A のまま）
8. 字幕の単語をクリックして、ポップアップに **「✓ 保存」「★ 覚えたい」「✕」** が並ぶことを確かめます。
9. 1語は「✓ 保存」、別の1語は「★ 覚えたい」で保存します。アプリで、**両方がその話の単語リスト**に出て、**★の語が単語帳**に入ることを確かめます。
   - いまはまだ「単語帳に自動で入れない」切り替え（公開日の作業）をしていないので、「✓ 保存」の語も単語帳に入ります。今日はそれで正常です。
10. アプリで★を外した語を、拡張でもう一度「✓ 保存」します。**★が付き直らない**ことを確かめます。

## C. ストア用の写真を1枚撮る（5分）
11. ブックマークバーを隠し（⌘⇧B）、ウィンドウを横に大きく広げる。
12. 英語字幕で再生し、**暗い場面か、場面の切り替わりの黒い画面**で一時停止。人の顔や作品のロゴが大きく映る場面は避けます。
13. 作品名や名前の入らない短いセリフの、ありふれた単語をクリック。訳が出るまで待ち、3つのボタンが並んだ状態で、マウスをボタンから離します。**⌘⇧4 → スペース → ウィンドウをクリック**で保存。保存ボタンは押さずに ✕ で閉じます。写真の場所を受付に伝えてください（アカウント名や作品名が写っていても、切り落としと暗くする加工はこちらでします）。

## D. 1時間たってもログインが続くか（待ち時間1時間）
14. A でログインしたまま、**アプリのタブを閉じて1時間以上**待ちます（Netflix などのタブは開いたままで構いません）。
15. 動画で単語を1つ「✓ 保存」してから、アプリを開き直します。**ログインしたまま**で、その語が単語リストに届いていればOK。以前はここでログインが切れることがありました。

## E. ゲストの語（5分）
16. もう1つ確認用プロファイルを作り（手順1と同じ）、手順2と同じフォルダを読み込みます。開いたアプリのタブで、まず `https://cinelearn-next.vercel.app/app?cl_staff=1` を開いて「運営の端末」の印を付けます。そのあとアプリは**ログインせずに閉じ**、動画で語 Y を「✓ 保存」。そのあとアプリで A にログインし、**Y が A の単語リストに届く**ことを確かめます。

## 後片付け
17. アプリで確認用の語を削除してから、確認用プロファイルを2つとも削除します（右上の人のアイコン → 歯車 → プロファイルの「…」→ 削除）。

## うまくいかない時
どの手順で、何が見えたか（画面の写真があれば）を受付に伝えてください。ほかの手順は止めずに続けて構いません。
