## 3. 詳細説明（Detailed description）

```
CineLearn は「ドラマを観る時間」を、そのまま英語学習のルーティンに変える学習支援ツールです。

■ こんな人へ
・洋画・海外ドラマは観るけど、単語がなかなか定着しない
・学習のために動画を止めると没入感が消えて続かない
・単語帳の例文より、「あのシーンのあのセリフ」で覚えたい

■ できること
1.【字幕の単語をワンクリック保存】
   視聴中に字幕の知らない単語をクリックするだけで、あなたの単語帳に保存されます。
   動画を止めてメモする必要はありません。単語にマウスを乗せると日本語の意味がすぐに出ます
   （同梱の英和辞書を使うため通信は不要です）。字幕をドラッグすれば句（フレーズ）も保存できます。

2.【AIが重要単語を自動抽出（予習）】
   エピソードの重要語だけを事前に抽出。基礎単語は自動スキップし、
   本当に覚えるべき語に絞って予習できるので、視聴中はドラマに集中できます。
   （予習・復習は連携する学習アプリ上で行います）

3.【間隔反復（SM-2）で復習】
   「忘れる前のちょうどいいタイミング」で復習を提案。
   「知ってた／うろ覚え／知らなかった」の3段階採点で、定着を助けます。

4.【実際のセリフが例文になる単語カード】
   保存した単語には、実際のセリフ例文・出典（作品名・話数）が付きます。
   「この単語、あのシーンで出てきた」という文脈ごと思い出せます。

5.【字幕の中で「知っている単語」が分かる】
   保存した単語と、この話の単語リストの語は、字幕の中で淡いクリーム色に表示されます。
   他の作品で保存・復習した単語が出てくると細い点線が付き、マウスを乗せると
   「どの作品で出会った語か」が分かります。再生中の没入を妨げない控えめな表示で、設定でオフにもできます。

6.【◀▶で前後のセリフへ移動】
   聞き取れなかったセリフの頭に戻る／次のセリフへ進む操作を、字幕単位で行えます。

■ 対応サービス
Netflix / Amazon Prime Video / Disney+
※ 一部のサービスでは、◀▶ の移動範囲が読み込み済みの字幕の範囲に限られます。

■ 料金
現在はベータ版として無料で公開しています。正式版では一部の機能が有料になる場合がありますが、
保存した単語帳と学習記録はそのまま残ります。

■ ご利用にあたって
・CineLearn は個人開発のツールで、動画配信サービス、作品情報・字幕データの提供元、AI・翻訳サービスの各事業者とは独立しており、いずれとも提携・公認関係にありません。各社の名称・商標は各権利者に帰属します。
・字幕の著作権は各権利者に帰属します。本ツールは学習目的で字幕の単語・短い例文を、出典を明示したうえで引用・表示します。
・DRM の解除・動画やコンテンツのダウンロード・再配布は一切行いません。

■ プライバシー
収集する情報と利用目的はプライバシーポリシーに明記しています。
個人情報を販売することはありません。
https://cinelearn-next.vercel.app/privacy

お問い合わせ・削除依頼: cinelearn.202606@gmail.com
```

## 8. 審査で突っ込まれやすい点への備え

- **リモートコード**: content.js ほか全スクリプトは同梱のみ・外部JSのeval/injectなし（Manifest V3準拠）。

- **著作権/提携**: 説明文・スクショで「Netflix公式」等と誤認させない。非提携文は説明文に含めるが**固有名詞を列挙しない一般形**（§3末尾）。列挙すると「過剰なキーワード」で不承認になる（2026-10-08 実績）。
- **効果の主張**: 「効果◯倍」「確実に定着」等の未裏付け表現は使わない（間隔反復・実セリフ例文など、実装事実と研究裏付けの範囲のみ）。
- **有料誘導なし**: 現状は完全無料。ストア内課金・外部決済への誘導は無し＝審査シンプル。
- **セッションブリッジ**: cinelearn-next ページの localStorage からログインセッションを拡張ストレージへ引き継ぐ設計は、自社ドメイン限定・ユーザー自身のログイン情報のみ・PPに記載済み、と説明できるようにしておく。

### 9.5 データ開示（Privacy practices）の確認

ストアの公開ページには現在「個人を特定できる情報／認証に関する情報／**位置情報**／**ユーザーのアクティビティ**／ウェブサイトのコンテンツ」の5つが表示されている（2026-10-17 実測）。
- **位置情報**: 実装は IP アドレスを Upstash のレート制限で最長24時間保持するだけ（拡張自体は GPS・住所を扱わない）。ダッシュボードの「位置情報」カテゴリの例示には IP アドレスが含まれるため、申告自体は規約上の保守的運用として維持する。代わりに §9.3 の「プライバシー」節で意味を1行説明し、PP の記載と一致させる。**外す判断をするなら、ダッシュボードの例示文を実際に読んで IP が含まれないことを確認してから**（本 docs では未確認）。
- **ユーザーのアクティビティ**: §6 の「ユーザーが作成したコンテンツ」は CWS のカテゴリ名ではなく、提出時にこの項目へ丸めた扱いになっている。クリックした単語・再生位置（再会の記録）の保存は「クリック等の操作」に当たるので妥当。§6 の表記をこのカテゴリ名に揃える。
