# あゆみ画面に「CEFR 段階ごとの覚えた語数」を出す案 — 事前確認（2026-11-05・ホーム・あゆみ部門）

受付からの依頼（オーナー 2026-11-05）に対する6点の確認。実装・デプロイはしていない。モック＝同じフォルダの `mock.html`（案A・案B／スマホ・PC／ダーク切替つき）。

## 0. 先に結論

- **数え方は既存のまま使える**: 「覚えた」＝ `isLearned`（2回以上正解・スキップ除外、マスターを含む）、母数＝3重の円と同じ `collectRingWords`（予習の生成語＋単語帳の保存語を語で名寄せ・棚から外した作品も含む）。新しい定義は作らない。
- **段階は単語リスト／単語帳と同じ出どころ**: 表の段階 `levelShown`（字幕由来・品詞一致・10/30 以降のリスト）→ 無ければ AI の `level`（A2〜C2）→ どちらも無い語（句動詞・言い回し）は「目安なし」として数だけ添える。サーバには問い合わせない（法務の線のまま）。
- **ただし 2026-10-08 のオーナー決定と正面から重なる**: 「レベル別タブ（CEFR 分布）はやめる＝どのアプリでも出せるのでコンセプトとずれる」（docs/design-paid-features-2026-10-08.md「統計の詳細の方針転換」）。今回の依頼はこれを取り消す判断になるので、**受付からオーナーに「10/8 の決定を上書きする」ことを一言確認**してほしい。
- 規模は小さい（0.5〜1日・端末内の計算だけ・DB/API/同期は触らない）。feat/first-run-trial との重なりは無い。

## 1. 「覚えた」の定義（既存にそろえる）

| 場所 | 定義 | 備考 |
|---|---|---|
| SRS（lib/storage.js） | `isLearned` = repetitions ≥ 2・skipped でない／`isMastered` = reps ≥ 3・interval ≥ 21・EF ≥ 2.0 | 覚えたはマスターを含む |
| 3重の円・週ごとの推移（あゆみ） | `collectRingWords` → `ringCounts`。値は **最高値**（`settleRingValues`＝忘れて外れても縮まない） | 母数＝履歴の語＋単語帳の語（和集合・語で1つ・skipped 除外・棚から外した作品の語も含む） |
| ホームの2タイル・（非表示中の）復習一覧の全体バー | `overallVocabStats` | 母数が少し違う（棚から外した作品の未復習語を除く）。円とは数字がずれうる |

提案: **円と同じ `collectRingWords` を母数にする**（同じ画面で2つの数え方を並べない）。段階別の内訳の合計＝円の「覚えた」の現在値。

注意点1つ: 円の数字は「最高値」なので、忘れて `isLearned` が外れた語がある間は、段階別の合計が円より小さくなる。選択肢:
1. 第1版は現在値で出し、「円は最高値」のずれを許容（カードを円の下に置き、合計は出さない＝案A）。
2. 段階ごとの最高値も端末に残す（`cl_ring_seen` と同じ要領のローカル記録・同期しない）＝棒が縮まない。端末ごとに値が違いうる。
3. `cl_stats_daily` に段階別の列を足して同期（max マージ）＝正攻法だが同期と週次集計に手が入る。

推奨は **1 → 様子を見て 2**。3 は今回の規模に合わない。

## 2. 語の段階の決め方

- **出どころの優先順**（単語リスト・単語帳の `cefrHintOf` と同じ規則）: ① `levelShown`（表の段階。/api/vocab-generate が字幕由来の語にだけ付け、`cl_history` に保存される。10/30 の本番以降に開いたリストのみ）② AI の `level`（生成時に A2〜C2 を付与。**A1 は AI からは出ない**＝A1 は表の語だけ）③ 無し。
- **句動詞・言い回し（空白を含む語）**: 既存どおり段階を付けない → 「目安が付かない語 ○語」と1行で添える（棒にはしない・モック参照）。
- **保存語（my_words）**: レコードは level を持たない。単語帳と同じく `cefrIndexFromHistory` で端末の `cl_history` から同じ語（品詞一致）の値を借りる（法務 10/30 追補で承認済みの方式・サーバ照会なし）。履歴に無い拡張・手入力の語は「目安なし」。
- **重複**: `collectRingWords` が語の小文字で名寄せ済み（同じ語を2作品で保存しても1語）。
- **表の値と AI の値が混ざる**: 単語リストも同じ混在なので、1行の注記（CefrNote 相当）で「表にない語は AI 推定」と伝える。表の語だけに絞る案（純度は高いが古い履歴の語がほぼ全部「目安なし」になる）は不採用を推奨。
- **古い利用者ほど AI 値が多い**: 10/30 以前の履歴には `levelShown` が無い。時間とともに表の値が増える。注記で足りる。
- **初回体験（feat/first-run-trial）の語**: 体験のクイズは SRS を書き換えない設計（design doc §オーナー決定 2）＝数に入らない。

実装上は `collectRingWords` の出力に `levelShown` を1項目足すだけで足りる（今は `level` しか写していない）。

## 3. 表示の案（mock.html）

- **案A 横棒（分母なし）**: 段階ごとに「覚えた」の数と棒（長さは最多の段階を基準にした相対値）。マスターは内数として濃い色を重ねる。分母も割合も出ない＝「残り」が見えない。**推奨**。
- **案B 出会った語を下地にした積み上げ**: 円と同じ3層（出会った／覚えた／マスター）を段階ごとの柱に。読み方の説明がいらない反面、「覚えていない量」が見える分だけ案Aより圧がある。
- **分母について**: 表の語数（A1 1,088 … C2 946）とは**比べない**。ほぼ全員が1桁%になってやる気を落とすし、表の段階別の語数を画面に出すこと自体が「表の構造の書き出し」に近づく。分母を置くなら本人が出会った語（案B）まで。
- **置き場所**: 円のカード（最近覚えた語を含む）の直後・「学習した日」の前に1枚の `vj-card`。円が無料で出ている間はこのカードも同じ扱い（あゆみ自体が `featureAccess('ring')` の中）。
- **数字が少ない間**: 覚えた語が 0 の段階は薄い棒（0 を赤くしない）。覚えた語が全体で 0 の人はカードごと出さない。
- **11月末の「いまの目安」との関係**: 同じ画面に「段階別の覚えた数」と「スコアの目安」が別々に並ぶと重い。このカードの下段に「いまの目安」の1行を足す形（1枚に統合）を前提に作っておくと、11月末にカードを増やさずに済む。

## 4. 既存の方針との整合

- **🔴 2026-10-08 オーナー決定（docs/design-paid-features-2026-10-08.md「統計の詳細の方針転換」）**: 「やめる: …／**レベル別タブ（CEFR 分布はどのアプリでも出せる＝コンセプト『観たいドラマが教材になる』とずれる）**／作品別タブ」。今回の依頼はこれの復活にあたる。背景が変わった点（10/30 に表の段階が入り、単語リスト・単語帳で各語に目安が出るようになった＝今は「どのアプリでも出せる」ではなく「自分の作品の語に付いた目安の集計」）はあるが、**決定の上書きはオーナーに明示確認**してほしい。
- **2026-10-31**: 復習一覧の全体「覚えた・マスター」バーを「余計だったかも」で非表示（`SHOW_HUB_OVERALL=false`）。数字のカードを増やす方向に慎重な流れなので、あゆみ 1 か所に限る・ホームには出さない、を提案。
- **苦手判定の廃止（10/8〜）**: 無関係（苦手は使わない）。
- **罪悪感 UI 禁止**: 割合・残り・下がる数字を出さない（§1 の最高値の扱い、§3 の分母なし）。
- **あゆみの構成**: 円→（新カード）→学習した日→週ごとの推移。`JOURNEY.text` に文言を集める既存の作りに合わせる。

## 5. 法務のガード

既に決まっている条件（public-launch-legal-posture.md 2026-10-30 の3件）:
- 表の段階は字幕由来の語リストにだけ付けて返す。任意の語の照会 API・一覧書き出し・CSV 列追加は不可。端末の `cl_history` から借りる方式は承認済み。
- 表現: 「公式」「認定」「判定」を使わない／全語を「CEFR-J レベル」と呼ばない／TOEIC の点数と並べない／1行の注記（CEFR-J・Octanove（CC BY-SA 4.0）／表にない語は AI 推定／出典→/terms#third-party）。
- 規約§10・THIRD_PARTY_NOTICES は「単語リストと単語帳」の文言。

**文言案**（モックと同じ）
- 見出し: 「段階ごとの覚えた語」 副題: 「CEFR目安」
- 各段階: 「A1」「A2」…「C2」と数だけ。本人の段階は言わない。
- 注記: 単語リストの CefrNote と同文（PC 長文／スマホ短縮）＋「目安の付かない語（句動詞など）は含みません」
- 使わない: 「あなたは B1」「B1 達成」「レベル判定」「TOEIC ○点相当」「公式」「認定」

**法務に聞く点**
1. 段階ごとの**個数の集計表示**（語は列挙しない）は「一覧書き出し」に当たらないか。表の値と AI の値を区別せずに数える点も含めて。
2. 表示範囲を「単語リストと単語帳」から「あゆみ」へ広げるため、規約§10・THIRD_PARTY_NOTICES・CefrNote の「単語リストと単語帳」の文言に「学習の記録（あゆみ）」を足す必要があるか（⑤部門の作業）。
3. 段階をタップしてその段階の語を一覧する機能を付けるなら（第1版では付けない）、本人の語の一覧＝単語帳の絞り込みと同じ扱いでよいか。
4. 利用データに「このカードが表示された」1項目を足す場合（§6）、ポリシーの「各機能の利用回数」で読めるか。
